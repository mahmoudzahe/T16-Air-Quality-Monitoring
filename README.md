# Real-Time Air Quality Monitoring and Analysis

Big Data Engineering Course Project – Team T16

## Project Overview
This project aims to monitor air quality using simulated IoT sensor readings and a real-time big data processing pipeline.

## Technologies
- Apache Kafka
- Apache Spark SQL
- Spark Structured Streaming
- Bloom Filter
- MongoDB
- Python

## Dataset
Approximately 20,000 simulated air quality sensor readings from 10 sensors across 4 locations.
